# MNPのりかえ Navi

**その乗り換え、本当にお得？** — 森樹エンジニアリング

日本国内の携帯電話のMNP乗り換えについて、6・12・24か月の現金支出と損益を比較する静的Webサービスです。ToolNestとは独立しています。無料・登録不要で、入力条件はブラウザ内で計算し、サーバーへ送信・保存しません。

## 開発

Node.js 24 と Python 3 を使用。ランタイム・ビルドとも外部npmパッケージは不要です。

```sh
npm test
python3 -m unittest discover -s tests -p 'test_*.py'
npm run build
npm run preview
```

出力は `dist/`、プレビューは `http://localhost:4173`。外部API・データベースは不要です。Cloudflare Pages の静的配信と互換性があります。Pages Functionsは使用しません。

## 実装

- 12ブランドの契約元選択と料金・データ使用量・通話条件の入力
- 詳細条件：期限付き割引、契約開始日、既存契約の値上げ、残債、新端末、重複請求、確認済み解約料
- ブラウザ内の損益計算・比較期間別ランキング（広告報酬は不使用）
- 6/12/24か月比較表、24か月累計グラフ、損益分岐点、CSV出力
- 確認済み条件のみ割引算入。ポイントと現金の区別、受取時期を扱える特典モデル
- 公式参照先・確認日・比較対象外の理由を表示
- 12ブランドの説明ページ、独自解説、運営者情報、プライバシー・広告ポリシー
- title/description、JSON-LD、公開URL設定時のcanonical・sitemap、robots.txt
- 広告領域、承認済みアフィリエイトリンク管理。広告スクリプトは未導入
- 公式ページの変更検知と確認候補PR、CI

## 料金データ

2026年10月19日に調査。12ブランド・代表21プランを確認済みとして収録しています。ワイモバイルは運営者から提供された公式料金画面・注意事項を照合し、S/M/Lを追加しました。全プラン・全通話オプションを網羅しません。

確認済み：NTTドコモ、au、ソフトバンク、楽天モバイル、ahamo、povo、LINEMO、UQ mobile、ワイモバイル、IIJmio、mineo、日本通信SIM。

- `data/catalog.json`：本番に使える確認済みデータと未確認データ。未確認値はnull・pendingとし、0円に置換しません。
- `data/candidates/latest.json`：自動検知の未承認候補。金額文字列は料金プランを表すとは限りません。
- `research/baseline.json`：公式ページ正規化テキストのSHA-256。本文は保存・再配布しません。
- `data/ads.json`：広告承認・提携リンク設定。初期状態ではすべて無効です。

確認記録・制限は [docs/data-review.md](docs/data-review.md)、競合調査は [docs/research.md](docs/research.md) を参照してください。確認期限は確認日から最大30日。期限切れ・不足データ・条件未確認は計算対象から除外します。

## 更新

```sh
npm run check:updates
```

毎週月曜06:17（日本時間）にGitHub Actionsが公式ページの変更・取得失敗を検知し、`bot/tariff-candidates` のPRにまとめます。参照URL・ハッシュ・観測金額を保存します。確認済み料金は自動で書き換えず、自動マージもしません。確認期限の7日前以降もレビュー対象に含めます。担当者が公式条件を確認し、カタログと確認記録を更新してから反映します。

GitHubの「Allow GitHub Actions to create and approve pull requests」を有効にする必要があります。作成されるのはPRのみで、レビュー・承認・マージは人が行います。`GITHUB_TOKEN` が生成したPRは通常のPRイベントを起動しないため、候補作成ジョブ内でテスト・ビルドを先に実施し、確認済み料金を編集したコミットではCIを再実行してください。

[docs/deployment.md](docs/deployment.md) にCloudflare Pagesの設定・公開前確認を記載しています。[docs/monetization.md](docs/monetization.md) に広告収益化に必要な作業を記載しています。

## 既知の制限

全プラン・全割引・全キャンペーン、契約条件別の解約料自動判定、日割り・請求締め日、端末返却・残価免除、世帯全体の自動計算は未対応です。法定付加料金、SMS、対象外通話、セット回線やカードの費用等は比較範囲外で、総請求額ではありません。詳細はサイト内の計算方法でも明示しています。

AdSenseの実スクリプト配信は、申請承認・プライバシー/同意管理・CSP見直し後に実装する必要があります。現在は広告なしでも動作する領域と設定検証を用意しています。
