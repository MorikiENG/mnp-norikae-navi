# 公開・収益化までの共同作業

一度に全部の設定を変更せず、完了条件を確かめながら進める。ログイン・本人確認・提携申請・公開判断は運営者が行う。実装・調査・検証はCodex側で進める。

| 順番 | 残作業 | 運営者の操作・判断 | 完了条件 |
| --- | --- | --- | --- |
| 1 | 変更検知の自動PR | GitHub ActionsのPR作成許可を有効化 | ワークフローが成功し、既存PRを自動更新できる |
| 2 | 料金データ再確認 | 自動取得不能な公式情報の確認に協力 | ワイモバイルの料金・容量・通話・手数料・適用日を確認して収録。全収録プランの出典を再照合 |
| 3 | 比較機能の補完 | 対象とする契約・特典条件を確認 | 通話オプション・解約条件・キャンペーンを確認済みの範囲で拡張し、未対応条件を明示 |
| 4 | 画面確認環境 | Cloudflareログインと配信範囲の決定 | 本人が配信を承認した確認用URL、または端末内プレビューを準備 |
| 5 | 実機確認・修正 | スマートフォンで入力・計算を確認 | Safari/Chrome、狭い画面、CSV、入力エラー、広告ブロック時の操作を検証 |
| 6 | 運営情報の確定 | 公開する問い合わせ窓口を指定 | GitHub未利用者も利用できる連絡手段とポリシーを確定 |
| 7 | 本番公開 | 料金・計算・画面の確認後に公開承認 | PagesのHTTPS・ヘッダー・canonical・sitemap・robotsと実際の計算を確認 |
| 8 | 収益化 | AdSense・ASP等へ本人が申請 | 承認後に実広告・リンク・必要な同意管理・ads.txtを実装し再検証 |
| 9 | 公開後の運用 | Search Console登録・通知先を確定 | インデックス確認、週次検知の継続、期限内の料金再確認 |

## 今回追加した公開前検証

本番ビルドを一時ディレクトリで生成し、canonical、サイトマップ、robotsの整合性、確認中ページの検索除外を検証した。外部配信はしていない。PUBLICATION_APPROVEDの値が文字列falseの場合に公開承認として扱わないことも確認。Node33件＋Python6件、計39件が成功。

## 保留理由

- ワイモバイル公式ページは開発環境・Web取得とも403。金額や条件は推測しない。
- ActionsによるPR作成は前回の実行でリポジトリ設定により拒否。設定変更の連絡後に再実行する。
- Cloudflare認証は未接続。認証情報やパスワードをチャットで送信する必要はない。
