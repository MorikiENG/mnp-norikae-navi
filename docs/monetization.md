# AdSense自動広告の導入状況

運営者の審査通過申告と明示依頼に基づき、承認記録とpublisher IDをdata/ads.jsonへ保存。本番ビルドの全HTMLページ（診断ページを含む）のheadに非同期ローダーを一度だけ挿入する。Google所有権確認用HTMLファイルは指定本文を維持する。プレビューは広告を配信しない。

共通CSPは本番広告有効時にGoogle広告の配信先を許可し、プライバシー・広告掲載ポリシーを更新。アフィリエイトは無効のまま。計算処理は広告ロードを待たない。

運営者はAdSense管理画面で自動広告を有効化し、配置・表示数を確認する。EEA・英国・スイス向け配信に必要なGoogle認定CMPはAdSenseの「プライバシーとメッセージ」で設定する（管理画面への設定は未実施）。ads.txtはAdSenseが提示する内容を確認後に設置する。実広告の表示・各地域の同意画面・広告ブロック時の実機確認は未確認。
