# 広告収益化の準備

## 初期状態

広告掲載領域だけを確保し、AdSenseスクリプト・広告Cookie・アフィリエイトリンクは配信していない。通常の公式リンクは報酬リンクではない。広告ブロックに計算処理が依存しない。

## アフィリエイト

本人がASPまたは広告主に申請し、承認された提携だけを `data/ads.json` の affiliates に追加する。

```json
{
  "carrierId": "ahamo",
  "label": "承認済み申込リンク",
  "url": "https://承認されたURL",
  "approved": true,
  "approvalRecord": "提携承認日・管理番号等（秘密を含めない）"
}
```

未承認エントリーはビルド時に表示しない。承認済みはキャリアページで「広告・PR」と明示し、`rel="sponsored noopener noreferrer"` を付ける。料率は計算エンジンに渡さない。

## AdSense

1. 運営者・連絡先・独自コンテンツ・料金の正確性を確定して公開承認を行う。
2. 本人のGoogleアカウントから申請し、サイト審査を受ける。
3. 承認後にpublisher IDとslot IDを登録。`approved` だけを切り替えても実スクリプト配信は始まらない。
4. 第三者送信の説明、広告Cookie、地域に応じた同意管理（必要な地域ではGoogle認定CMP）を実装し、プライバシーポリシーを更新する。
5. `ads.txt` は本人の承認済みpublisher IDから作成する。架空のIDや他者のIDを使用しない。
6. 広告ローダーと実slotを実装し、CSPで必要なGoogleの配信元だけを許可する。現在のCSPは第三者スクリプトを拒否する。
7. 実機で配置・誤クリック・レイアウト変動を確認。広告無効時、拒否時、ブロッカー使用時でも計算を検証する。

広告提携申請、Googleログイン、AdSense申請は未実施。承認前の表示や自己クリックを行わない。
